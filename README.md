# DebHypr — Development ISO

### Debian 13 Trixie • Hyprland • Quickshell • Live ISO

> **Development build:** This repository contains the **current development version of the DebHypr Live ISO**. It is **not the official Beta 1.0.0 release build**. The released version of DebHypr is currently **Beta 1.0.0**, while this ISO is actively being developed and tested as the basis for the **upcoming Beta 2.0.0 release**.

The configuration in this branch can change at any time as new features, fixes, improvements, and experiments are added and tested.

The official **Beta 1.0.0** release should be treated as a separate, frozen snapshot. The ISO produced from this development branch should instead be considered a **pre-Beta 2.0.0 development/test build**.

In simple terms:

```text
Official Release
      ↓
  Beta 1.0.0
      │
      │
      └──── Development continues
                    ↓
             Current Test ISO
                    ↓
             Beta 2.0.0
                    ↓
             Next Official Release
```

**This README describes the current development ISO, not the released Beta 1.0.0 ISO.**
